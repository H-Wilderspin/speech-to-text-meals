# Shared meal plans

Public meal data for https://h-wilderspin.github.io/speech-to-text/.

Each `weeks/YYYY-MM-DD.json` file starts on Monday and has `version: 1` and a `meals` object. Keys are `YYYY-MM-DD/breakfast`, `/lunch` or `/dinner`; values are plain text up to 300 characters. Delete a key to remove a meal. An absent week is empty.

Meal contents and Git history are public. No credentials, audio or transcripts belong here.

Editing setup: https://github.com/H-Wilderspin/speech-to-text/blob/main/docs/meal-planner.md
